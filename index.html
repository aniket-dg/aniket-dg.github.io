About

My journey started during a diploma project where I discovered that most bugs aren't really bugs — they're two systems disagreeing about what a "record" is. I've been sorting out that disagreement professionally ever since.

Today that means building HRIS and ATS integrations at Journeyfront Inc — webhook contracts, async pipelines, and the field-mapping logic that lets a dozen vendors describe the same employee in a dozen different ways. I spend a fair share of my time on the infrastructure around the code too: CI runners, migrations, and enough hours in Sentry to have strong opinions about which errors deserve a page at 2am.

Outside of work I build smaller things end-to-end, from an investment tracker to a real-time collaborative code editor — mostly because I like seeing an idea go from a blank repo to something a friend actually uses.
